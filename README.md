## Deployment

### Podman Compose

**1.** Save as `.env` and fill in what is empty:

```env { data-zip-bundle="outline-podman" data-zip-filename=".env" }
# Outline for FreeBSD (Daemonless)
# Copy to .env and edit.

# Where data lives on the host
CONFIG_LOCATION=/containers/outline/config
POSTGRES_DATA_LOCATION=/containers/outline/postgres
REDIS_DATA_LOCATION=/containers/outline/redis

# Public URL Outline is reached on. Must match what the browser uses.
URL=http://localhost:3000
WEB_HOST_PORT=3000

# Set a strong password before the first start.
POSTGRES_PASSWORD=

PUID=1000
PGID=1000
TZ=UTC
```

**2.** Save as `compose.yaml`:

```yaml { data-zip-bundle="outline-podman" data-zip-filename="compose.yaml" }
name: outline

services:
  outline:
    image: ghcr.io/daemonless/outline:latest
    container_name: outline
    restart: unless-stopped
    depends_on:
      - postgres
      - redis
    environment:
      - PUID=${PUID:-1000}
      - PGID=${PGID:-1000}
      - TZ=${TZ:-UTC}
      - URL=${URL}
      - PORT=3000
      - SECRET_KEY=${SECRET_KEY:-}
      - UTILS_SECRET=${UTILS_SECRET:-}
      - DATABASE_URL=postgres://outline:${POSTGRES_PASSWORD}@${POSTGRES_HOSTNAME:-postgres}:5432/outline
      - PGSSLMODE=disable
      - REDIS_URL=redis://${REDIS_HOSTNAME:-redis}:6379
      - FORCE_HTTPS=${FORCE_HTTPS:-false}
      - SMTP_HOST=${SMTP_HOST:-}
      - SMTP_PORT=${SMTP_PORT:-}
      - SMTP_USERNAME=${SMTP_USERNAME:-}
      - SMTP_PASSWORD=${SMTP_PASSWORD:-}
      - SMTP_FROM_EMAIL=${SMTP_FROM_EMAIL:-}
      - SMTP_SECURE=${SMTP_SECURE:-true}
      - OIDC_CLIENT_ID=${OIDC_CLIENT_ID:-}
      - OIDC_CLIENT_SECRET=${OIDC_CLIENT_SECRET:-}
      - OIDC_ISSUER_URL=${OIDC_ISSUER_URL:-}
      - OIDC_DISPLAY_NAME=${OIDC_DISPLAY_NAME:-OpenID Connect}
    volumes:
      - ${CONFIG_LOCATION}:/config
    ports:
      - target: 3000
        published: ${WEB_HOST_PORT:-3000}

  postgres:
    image: ghcr.io/daemonless/postgres:18
    container_name: outline-postgres
    restart: unless-stopped
    annotations:
      org.freebsd.jail.allow.sysvipc: "true"
    environment:
      - POSTGRES_USER=outline
      - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
      - POSTGRES_DB=outline
      - PUID=${PUID:-1000}
      - PGID=${PGID:-1000}
      - TZ=${TZ:-UTC}
    volumes:
      - ${POSTGRES_DATA_LOCATION}:/var/lib/postgresql/data

  redis:
    image: ghcr.io/daemonless/redis:latest
    container_name: outline-redis
    restart: unless-stopped
    environment:
      - PUID=${PUID:-1000}
      - PGID=${PGID:-1000}
      - TZ=${TZ:-UTC}
    volumes:
      - ${REDIS_DATA_LOCATION}:/config
```

Then run `podman-compose up -d`.
Open `http://<server>:${WEB_HOST_PORT:-3000}` from another machine (the server's own browser can't use a published port).

## Setup Instructions

The first visit asks for a workspace name and an admin account, and signs you in. To sign in again later, Outline needs a way to prove who you are, because it has no passwords: set up `SMTP_*` for sign-in links by email, or `OIDC_*` for single sign-on. Other providers are in the [authentication docs](https://docs.getoutline.com/s/hosting/doc/authentication-7ViUmeMISY). Do this before you sign out.

`URL` must match what the browser uses. Behind a reverse proxy with TLS, set `URL` to the https address and keep `FORCE_HTTPS=false`, because the proxy handles the redirect.

Uploads are stored under `/config/data`. S3 storage does not work on FreeBSD: its AWS library needs a native binding that has no FreeBSD build.

`SECRET_KEY` and `UTILS_SECRET` are generated into `/config/secrets.env` on first start. Keep `/config`: a new `SECRET_KEY` signs everyone out and makes encrypted fields unreadable.

Outline uses the Business Source License 1.1, which is not an open source license. You can run it for your own team, but not as a commercial document service for others.
